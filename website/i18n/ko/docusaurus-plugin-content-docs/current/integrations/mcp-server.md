# MCP Server

MCP server는 model-context-protocol interface를 통해 graph-tool-call capability를
호출할 수 있게 합니다.

## Use Cases

- search를 reusable tool로 노출
- filtered tool catalog를 agent에 공유
- local/remote tool source를 하나의 interface 뒤에 연결
