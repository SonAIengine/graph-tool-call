# Report Schema

Report는 deterministic해야 하고 product metadata에 안전하게 저장될 수 있어야 합니다.

## OpenAPI Readiness Report

중요 section:

- `summary`
- `coverage`
- `graph_readiness`
- `issues`
- `recommendations`
- `semantic_coverage`
- `observed_contract_coverage`
